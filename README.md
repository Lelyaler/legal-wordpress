# Legal Corporate Theme — Custom WordPress Theme with Gutenberg Blocks

Кастомная тема WordPress для юридических компаний и консалтинговых агентств со встроенными нативными блоками Gutenberg (Block API) и автоматической микроразметкой Schema.org.

- **Live Demo (интерфейс):** [lelyaler.github.io/Legal-website/](https://lelyaler.github.io/Legal-website/)
- **Репозиторий верстки:** [github.com/Lelyaler/Legal-website](https://github.com/Lelyaler/Legal-website)

Тема собрана по стандартам кастомной разработки WordPress без использования тяжелых визуальных конструкторов (Elementor / WPBakery). Все посадочные секции вынесены в нативные блоки Gutenberg, что дает контент-менеджерам возможность собирать страницы прямо в стандартном редакторе WordPress.

---

## Ключевые особенности

- **Нативные блоки Gutenberg (Block API):** зарегистрирована отдельная категория `Legal Theme Blocks` в инсертере редактора.
- **Серверный рендеринг (`render.php`):** блоки рендерятся на стороне сервера, что исключает сдвиги макета (CLS 0) и гарантирует индексацию контента поисковыми роботами.
- **Автоматическая микроразметка Schema.org FAQPage:** блок часто задаваемых вопросов автоматически формирует валидный JSON-LD граф в подвале страницы для сниппетов в поисковой выдаче.
- **Доступность (A11Y):** семантическая разметка, поддержка навигации с клавиатуры и корректные ARIA-атрибуты (`aria-expanded`, `aria-controls`).
- **Интерактивные формы:** модальное окно на нативном теге `<dialog>` с быстрой записью на консультацию через AJAX.
- **Оптимизация производительности:** использование WebP, шрифты без блокировки рендера, чистый CSS без избыточных фреймворков.

## Встроенные блоки Gutenberg

1. **`legal/hero`** — главный экран с фоновыми изображениями, триггерами доверия и кнопкой вызова консультации.
2. **`legal/stats`** — блок с ключевыми числовыми показателями практики компании.
3. **`legal/services`** — каталог услуг и практик с быстрой заявкой.
4. **`legal/process`** — пошаговый таймлайн ведения дела клиента.
5. **`legal/faq`** — аккордеон с ответами на частые вопросы и генератором JSON-LD Schema.org.
6. **`legal/reviews`** — адаптивный слайдер отзывов на базе Swiper.

## Структура файлов

```text
legal-wordpress/
├── blocks/               # Нативные блоки Gutenberg
│   ├── faq/              # Блок FAQ с генератором Schema.org
│   ├── hero/             # Блок главного экрана
│   ├── process/          # Блок этапов работы
│   ├── reviews/          # Блок отзывов клиентов
│   ├── services/         # Блок направлений практики
│   └── stats/            # Блок показателей
├── css/                  # Стили темы и блоков
├── images/               # Графика и векторные ассеты
├── js/                   # Скрипты темы и логика модальных окон
├── swiper/               # Библиотека Swiper
├── footer.php            # Подвал сайта и модальное окно
├── front-page.php        # Шаблон главной страницы
├── functions.php         # Регистрация скриптов, стилей и блоков
├── header.php            # Шапка и навигация
├── index.php             # Базовый шаблон
├── page.php              # Шаблон стандартной страницы
└── style.css             # Заголовок темы WordPress и стили
```

## Установка

1. Склонируйте тему в каталог тем WordPress:
   ```bash
   cd wp-content/themes/
   git clone https://github.com/Lelyaler/legal-wordpress.git
   ```
2. Активируйте **Legal Corporate Theme** в панели управления: **Внешний вид → Темы**.
3. Создайте новую страницу в **Страницы → Добавить новую**.
4. Нажмите `+` и выберите нужные блоки из категории **Legal Theme Blocks**.
